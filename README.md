# Канбан Design 2025-2026

Статична сторінка (GitHub Pages) показує задачі з Google-таблиці як канбан-дошку й дозволяє їх змінювати.
Бекенд — Google Apps Script, прив'язаний до таблиці. Вкладка «Зведена таблиця» через API ніколи не читається.

## Налаштування (один раз)

1. **Apps Script.** Відкрийте таблицю → *Розширення → Apps Script*. Замініть вміст `Code.gs` вмістом
   [`apps-script/Code.gs`](apps-script/Code.gs), збережіть. У списку функцій виберіть `setup` → *Виконати*
   (дозвольте доступ до таблиці). Відкрийте *Журнал виконання* і скопіюйте ключ `ADMIN_KEY: …`.
2. **Розгортання.** *Розгорнути → Нове розгортання → тип «Вебдодаток»*;
   *Виконувати як*: **Я**; *Хто має доступ*: **Усі (Anyone)**. Скопіюйте URL, що закінчується на `/exec`.
   Після змін у коді: *Розгорнути → Керування розгортаннями → ✏️ → Версія: Нова версія* — URL не змінюється.
3. **Сторінка.** Впишіть URL у `const API_URL = "…"` у [`src/index.src.html`](src/index.src.html), потім:
   ```bash
   npm install
   ```
   ```bash
   npm run build
   ```
   Закомітьте й запуште `index.html`.
4. **GitHub Pages.** *Settings → Pages → Build and deployment: Deploy from a branch → `main`, `/ (root)`*.
5. **Вхід.** На кожному пристрої один раз відкрийте `https://<нік>.github.io/<repo>/#key=<ключ>` —
   ключ збережеться в браузері й зникне з адресного рядка. Змінити ключ: знову запустіть `setup()`.

**Ключ для інших.** Apps Script → *⚙️ Налаштування проєкту → Властивості скрипту → Додати*:
`USER_KEY` = ваш ключ для команди. Права ті самі, що й з `ADMIN_KEY`. Змінити або видалити його можна там само,
розгортання оновлювати не треба.

## Як це працює

- Нова вкладка-місяць з'являється на дошці сама, якщо в одному з перших 5 рядків є заголовок «Задача».
  Колонки шукаються за назвою («Годин»/«Години», «Дата»/«Дата виконання» тощо), порядок не важливий.
- Статуси беруться з випадного списку колонки «Статус»; невідомі статуси показуються окремою колонкою.
- Дедлайн можна задати з часом; тоді до формату клітинки додається `HH:mm`. Часовий пояс скрипта
  (*Apps Script → Налаштування проєкту*) має збігатися з поясом таблиці (*Файл → Налаштування*).
- Нова задача копіює оформлення і випадні списки (пігулки статусу, проєкту, відповідального) з рядка вище.
  Якщо в старих рядках пігулок немає — запустіть у Apps Script функцію `repairDropdowns`.
- Перехід у Done ставить сьогоднішню дату в «Дата»/«Дата виконання», якщо вона порожня.
- Задача визначається номером рядка + назвою. Якщо рядок у таблиці змінили — сторінка покаже
  повідомлення і перезавантажить дані. Рядки через сторінку не видаляються.
- Дошка оновлюється кожні 60 с, поки вкладка активна й нічого не редагується.

## Розробка

```bash
npm run dev
```
Локальний мок Apps Script з тестовими даними: http://localhost:8787/#key=test-key

```bash
npx playwright install chromium
```
```bash
npm test
```
Збирає сторінку й проганяє end-to-end тести в Chromium; скриншоти — у `test/screenshots/`.

Файли: `src/index.src.html` (розмітка + JS), `src/input.css` (Tailwind v4), `scripts/build.mjs`
(вбудовує зібраний CSS у `index.html`), `test/mock-apps-script.mjs` (мок), `test/e2e.mjs` (тести).
